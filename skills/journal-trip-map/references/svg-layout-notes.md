# SVG 布局调整与故障排查

## 画布

`viewBox="0 0 400 580"`，渲染宽度 = 卡片内容宽（约 400–440px），故 1 单位 ≈ 1.05–1.1 屏幕像素。**SVG 内最小字号 10.5**（约等于屏幕 11px），低于此值在手机上会糊。

## 常用运算

**聚集面板高度**：`h = 22 + 行数 × 17 + 6`
- 2 行 → 68；3 行 → 85（取 86）；4 行 → 102；5 行 → 119
- 行 y 坐标：`21, 41, 58, 75, 92, 109…`（首行标题 y=21，其后每行 +17）

**面板变矮后**：把 `cluster → final` 这条虚线的起点 y，改成新的面板底边（= `296 + h`）。
- 改前：`M 200 384 C 180 412, 155 445, 134 470`
- 面板 h=102（底边 398）→ 起点改 `M 200 400 C 180 425, 155 448, 134 470`

**删除节点**：除了删该 `<g>`，还要
1. 删/改相连的 `<path>`（否则虚线悬空）
2. 删对应的里程气泡
3. 删 Today's Route 里对应步骤
4. 重编号地图路钉与下方清单（编号必须一致）
5. 删掉标题汇总行、方位速读、图例中对该点的引用

**新增节点**：优先插在纵向空白处；横向空间紧张时，宁可把面板上移到 Canvas 中间，也不要把两个框并排放（手机横向会挤）。相邻元素留白 ≥ 20 单位。

## 常见故障：失败位置 → 根因 → 修复

| 现象 | 根因 | 修复 |
|---|---|---|
| 地图内有横向滚动 / 元素被切 | SVG 元素写到了 x>392 或超过 viewBox | 所有 rect/文本控制在 4–388；必要时缩短文案或换行 |
| 文字溢出白色贴纸框 | 英文地名过长 | 拆两行，或把附属说明（`{{*_SUB}}`）移到第二行小字 |
| 虚线路线悬空 | 面板缩矮后没改 path 起点 | 按上面的"面板变矮后"规则改控制点 |
| 编号对不上 | 删了步骤但没删路钉 | 地图圆形编号与 `.step` 列表一起删/增 |
| 中文字显示为方块 | 缺 CJK 字体回退 | font stack 里补 `'PingFang SC','Microsoft YaHei',sans-serif` |
| 断网后字体变丑 | Google Fonts 加载失败 | 已有降级到 `Comic Sans MS / system-ui`，属预期行为，不必修 |
| 边框"手绘感"消失 | 误删 `.card` 的复杂 `border-radius` | 恢复 §3 SKILL.md 中的 radius 写法，`.alt` 卡片用反向值 |
